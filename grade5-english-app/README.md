# 🇬🇧 תרגול למבחן מיפוי באנגלית - כיתה ה'

אפליקציה לתרגול לקראת מבחן המיפוי באנגלית (21.10.26), לפי החומר שפורסם על ידי המורה.
בנויה באותו סגנון כמו אפליקציית התרגול של כיתה ד' (`../`): מסך פתיחה עם דמות וצבע, אריחי נושאים, נקודות, רצפים, הישגים וספירה לאחור למבחן.

## ✨ הנושאים (לפי החומר למבחן)

| נושא | מה מתרגלים |
|------|------------|
| 📚 אוצר מילים | משמעות מילים (אנגלית↔עברית), התאמת מילה לתמונה, התאמת מילה להגדרה, השלמת משפט ממחסן מילים |
| 🟰 is / are | יחיד ורבים, There is / There are, שאלות |
| 🎒 has / have | he/she/it ← has, I/you/we/they ← have |
| 💪 can / can't | לפי ההיגיון של המשפט |
| ❓ because / why | Why שואל, because עונה + התאמת שאלה לתשובה |
| 🧩 סידור משפטים | בניית משפט תקין ממילים מעורבבות (עם רמז בעברית) |
| 📖 הבנת הנקרא | 8 קטעים: שאלות אמריקאיות, Yes/No, סידור אירועים לפי סדר |
| 🎧 הבנת הנשמע | 6 קטעים שהדפדפן מקריא בקול (אפשר גם לאט) + שאלות |
| ✍️ כתיבה | "איזה משפט כתוב נכון?" + כתיבת קטע על עצמי עם פתיחי משפטים, רשימת בדיקה אוטומטית וקטע לדוגמה |

📘 **שיעור "איך פותרים?"** לכל נושא (לפי דף הכללים): כרטיסי כללים עם דוגמאות, פתרון דוגמה צעד אחרי צעד, משחק מיון ובדיקה קצרה.
השיעור נפתח לבד בכניסה הראשונה לנושא, ואחר כך מכפתור "📘 איך פותרים?" בראש המסך.

🎧 **נגן הקראה**: עצירה והמשך מאותו משפט, התחלה מחדש, ו-3 מהירויות (לאט / בינוני / רגיל). הבחירה נשמרת.

🔊 בכל מקום שיש כפתור רמקול אפשר לשמוע את המילה / המשפט באנגלית (Web Speech API - בלי שרת ובלי מפתח API).

## ☁️ התחברות עם Google ושמירה בענן (Firebase)

לאפליקציה יש פרויקט Firebase משלה (נפרד מכל פרויקט אחר).
כל ילד/ה מתחבר/ת עם Google, וההתקדמות (פרופיל, נקודות, הישגים, סטטיסטיקה וטיוטת הכתיבה) נשמרת תחת
`english/users/<uid>` ב-Realtime Database ועוברת בין מכשירים. בלי אינטרנט האפליקציה ממשיכה לעבוד ומסתנכרנת כשהחיבור חוזר.
אפשר גם "להמשיך בלי התחברות" - אז הכול נשמר רק בדפדפן, ואפשר להתחבר מאוחר יותר מחלון עריכת הפרופיל (לחיצה על השם) וההתקדמות תעלה לענן.

האפליקציה מחוברת לפרויקט Firebase בשם `english-practice-87420` (הפרטים ב-`src/services/firebase.js`), כך שאין צורך במשתני סביבה.

**הגדרות שצריכות להיות בפרויקט ב-[Firebase Console](https://console.firebase.google.com):**
1. **Realtime Database ← Rules** - התוכן של [`database.rules.json`](database.rules.json) (כל ילד/ה קורא/ת וכותב/ת רק את הנתונים של עצמו/ה).
2. **Authentication ← Sign-in method ← Google** - מופעל.
3. **Authentication ← Settings ← Authorized domains** - כולל את כתובת האתר ב-Vercel. `localhost` כבר מאושר.

למעבר לפרויקט Firebase אחר או לעבודה בלי ענן - ראו [`.env.example`](.env.example).

## ⚙️ ממשק ניהול שאלות

מנהל/ת מחובר/ת רואה בכותרת כפתור **⚙️ ניהול**. שם אפשר, לכל נושא:
- **להוסיף שאלה** (טופס לפי סוג השאלה, עם בדיקה שהשאלה תקינה לפני השמירה).
- **למחוק** שאלה שנוספה, או **להסתיר** שאלה מובנית (ולהחזיר אותה אחר כך).

השאלות נשמרות ב-Firebase תחת `english/content` ומופיעות מיד אצל כל מי שמשתמש באפליקציה, גם בלי התחברות.
שאלות "מבחן מסכם" נלקחות מהשאלות של am/is/are, has/have, can/can't ו-because/why.

**הגדרת מנהל/ת (פעם אחת):**
1. להתחבר לאפליקציה עם חשבון ה-Google של המנהל/ת.
2. ב-Firebase: **Authentication ← Users** - להעתיק את ה-**User UID** של החשבון.
3. **Realtime Database ← Data** - להוסיף תחת השורש: `english` ← `admins` ← `<UID>` עם הערך `true`.
4. לרענן את האפליקציה - יופיע כפתור **⚙️ ניהול**.
