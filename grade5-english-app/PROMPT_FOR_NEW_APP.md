חלק ד' - מסכים ותכונות לתלמידים
══════════════════════════════════════
1. מסך התחברות:
   - כפתור "התחברות עם Google".
   - "כניסה עם שם משתמש וסיסמה" - לילדים בלי חשבון Google. לשוניות "כבר יש לי משתמש" / "הרשמה חדשה". שם משתמש 3-15 תווים (עברית או אנגלית, מספרים, _ או -), סיסמה לפחות 6 תווים, הצגה/הסתרה של הסיסמה, אימות סיסמה בהרשמה.
     מימוש: השם (באותיות קטנות) מקודד ל-hex של UTF-8 והופך לכתובת פנימית בסגנון u<hex>@kids.<הדומיין-שלכם> שמשמשת ל-Email/Password של Firebase. כך אין צורך באימייל אמיתי, Firebase מונע שמות כפולים, ועברית עובדת. להציג הודעות שגיאה ברורות בעברית (שם תפוס, שם/סיסמה שגויים, סיסמה קצרה, יותר מדי ניסיונות). להזכיר לרשום את הסיסמה - אין שחזור בלי אימייל.
   - "להמשיך בלי התחברות" - ההתקדמות נשמרת רק במכשיר.
2. מסך פתיחה (פעם ראשונה): שם, בת/בן, בחירת דמות (אימוג'י) וצבע לאפליקציה. אחריו - חלון הסבר קצר: איך מתרגלים, היעד, כמה ימים נשארו למבחן.
3. כותרת קבועה: שלום + שם + דמות (לחיצה פותחת עריכת פרופיל), נקודות, כפתור "ההישגים שלי", ספירה לאחור למבחן ("המבחן בעוד X ימים"), ☁️ כשמחוברים, ⚙️ ניהול רק למנהלים.
4. מסך הבית: אריח לכל נושא מהמבחן, עם אחוז התקדמות בעיגול צבעוני (יעד: 30 תשובות נכונות בנושא = 100%), ועוד אריח "מבחן מסכם".
5. סוגי תרגול - לבנות לפי הנושאים שלי. דוגמאות שעבדו מצוין:
   - אוצר מילים: מה הפירוש (אנגלית ← עברית), איך אומרים באנגלית, התאמת מילה לתמונה (אימוג'י), התאמת מילה להגדרה פשוטה באנגלית, השלמת משפט ממחסן מילים. מסיחים מאותה קבוצה (חיות, אוכל, צבעים...).
   - דקדוק (לכל כלל אריח נפרד, למשל am/is/are, has/have, can/can't, why/because): משפט עם ____ ובחירת המילה. אם החסר בתחילת משפט - האפשרויות באות גדולה. אחרי התשובה: המשפט המלא + הסבר קצר בעברית למה.
   - סידור מילים למשפט: אריחי מילים מעורבבים באותיות קטנות, בלי נקודה בסוף, וסימן שאלה כאריח נפרד (כמו בדף עבודה). שמות ו-I נשארים באות גדולה. רמז: תרגום לעברית. בטעות - לשמור את המילים שכבר במקום הנכון.
   - הבנת הנקרא: קטע קצר + שאלות: אמריקאיות, Yes/No, וסידור אירועים לפי הסדר.
   - הבנת הנשמע: הקטע מוקרא בקול והטקסט מוסתר (כפתור "הצגת הטקסט" רק אם ממש צריך).
   - כתיבה: (א) "איזה משפט כתוב נכון?" - 4 גרסאות של אותו משפט עם טעויות נפוצות; (ב) כתיבת קטע על עצמי עם פתיחי משפטים ללחיצה, רשימת בדיקה שמתעדכנת תוך כדי הקלדה (לפחות 6 משפטים, אות גדולה בתחילת משפט, נקודה בסוף, I גדולה, I am, have/has, can/can't, because, לא "I is"), קטע לדוגמה, והטיוטה נשמרת.
   - מבחן מסכם: 10 שאלות מעורבות מכל נושאי הדקדוק בפורמט "Circle the correct word" - ( is / are ) בתוך המשפט - ובסוף ציון וסיכום.
6. חוקי משחק וניקוד:
   - שאלה עם 2 אפשרויות - ניסיון אחד; 3-4 אפשרויות - שני ניסיונות; סידור משפט - שלושה. תשובה שגויה נמחקת ("נסי שוב").
   - נקודות: 15 בניסיון ראשון, 10 בשני, ועוד 5 לכל תשובה ברצף. "🔥 רצף של X" כשיש 3 ומעלה.
   - שאלות לא חוזרות עד שהמאגר נגמר.
   - 🔊 ליד כל מילה/משפט באנגלית.
7. שיעור "📘 איך פותרים?" לכל נושא - נפתח לבד בכניסה הראשונה לנושא, ואחר כך מכפתור בראש המסך. שלבים:
   - כרטיסי כללים צבעוניים (למשל AM ← I; IS ← he/she/it; ARE ← we/you/they) עם דוגמאות, המילה החשובה מודגשת, 🔊 לכל דוגמה.
   - פתרון דוגמה צעד אחרי צעד (לחיצה חושפת כל צעד): על מי מדברים ← מחליפים במילה קטנה ← בודקים בכלל.
   - משחק מיון: מילה/משפט מופיעים אחד-אחד והילד לוחץ על הקופסה הנכונה.
   - בדיקה קצרה עם הסבר מיד אחרי כל תשובה.
   - לנושאים שאינם דקדוק (קריאה, האזנה, כתיבה, אוצר מילים, סידור משפטים): טיפים "איך פותרים" + דוגמה.
   אם צירפתי דף כללים - להשתמש בכללים ובדוגמאות שלו.
8. נגן הקראה (האזנה + "הקראת הקטע" בקריאה): הקראה משפט אחרי משפט (כך עצירה והמשך ממשיכים מאותו משפט, ולא מההתחלה), כפתורי ⏸️ עצירה / ▶️ המשך / ⏮️ מההתחלה, פס התקדמות ו"משפט X מתוך Y", הדגשת המשפט שמוקרא, ו-3 מהירויות לבחירה: 🐢 לאט (0.6, ברירת מחדל) / 🚶 בינוני (0.75) / 🐇 רגיל (0.9). הבחירה נשמרת ומשמשת את כל כפתורי ה-🔊. (לא להסתמך על speechSynthesis.pause - הוא לא עובד באנדרואיד.)
9. הישגים ("ההישגים שלי"): סקירה כללית, הישגים (שאלה ראשונה, 5/10/20 שאלות, רצף 3/5/10, 50/100/200/500 נקודות) עם הודעה קופצת כשנפתח הישג, והתקדמות לכל נושא מול היעד; המלצה כמה תרגילים לעשות ביום עד המבחן.
10. כשחוזרים לאפליקציה: חלון "איפה את עומדת" - התקדמות כללית, ימים למבחן, נושאים שעוד לא התחילו ונושאים לחיזוק.
11. תזכורת הרשמה לאורחים: ילד שתרגל בלי להירשם וחוזר - פעם אחת בכל כניסה מקבל חלון ידידותי עם הדמות שלו: "היי נועה! טוב שחזרת 👋", "כרגע 85 הנקודות שצברת שמורות רק במכשיר הזה", למה כדאי להירשם (שום דבר לא ילך לאיבוד; מכל מכשיר; לא צריך אימייל), "זה לוקח פחות מדקה וכל מה שעשית עובר איתך", "כדאי לבקש מאמא או מאבא לעזור לשמור את הסיסמה". כפתורים "🚀 בואי נירשם!" (פותח ישר את טופס ההרשמה) ו"אולי אחר כך".
12. העברת התקדמות: אחרי הרשמה - כל מה שנשמר במכשיר עולה לחשבון החדש. אם אורח מתחבר לחשבון שכבר יש לו נתונים - ממזגים (נקודות וסטטיסטיקה מתחברות, הישגים/טעויות מתאחדים) ולא דורסים. נתונים של ילד אחד לעולם לא עולים לחשבון של ילד אחר באותו מכשיר; התנתקות מנקה את המכשיר.

חלק ה' - ממשק ניהול (רק למורה / למנהלים)
══════════════════════════════════════
מנהל = משתמש שה-UID שלו מופיע ב-english/admins/<uid> = true (מוגדר ידנית פעם אחת בקונסול של Firebase). רק הוא רואה כפתור ⚙️ ניהול, עם 3 לשוניות:
1. 📝 שאלות: לשונית לכל נושא; הוספת שאלה בטופס שמתאים לסוג השאלה (משפט עם ____ ותשובה, מילה+פירוש+אימוג'י+הגדרה+קבוצה, קטע קריאה עם שאלות אמריקאיות/Yes-No/סידור אירועים, וכו'), עם בדיקת תקינות לפני שמירה. מחיקת שאלות שנוספו, והסתרה/החזרה של שאלות מובנות. שאלות חדשות מופיעות מיד אצל כולם (קריאה ציבורית). המשחקים משתמשים במאגר המשולב (מובנות + חדשות - מוסתרות), ואם הכול הוסתר - חוזרים למובנות.
2. 📊 משתמשים: רשימת כל המשתמשים המחוברים (שם, אימייל או שם משתמש, נקודות, תשובות, אחוז הצלחה בצבע, פעילות אחרונה). לחיצה על משתמש: הצלחה לפי נושא מול היעד, "כדאי לעבור יחד על" (נושאים מתחת ל-80%), יומן טעויות (השאלה, מה נענה, מה התשובה הנכונה, האם תוקן בניסיון נוסף; סינון לפי נושא; עד 300 אחרונות), והקטע שכתב.
3. 📈 שימוש: כמה באתר עכשיו (presence עם onDisconnect), מבקרים היום / ב-7 ימים, כניסות, וגרף עמודות מוערמות ליום - מחוברים מול אורחים - ל-7/14/30 ימים, עם tooltip ותצוגת טבלה. מדידה אנונימית: לכל דפדפן מזהה אקראי בלי פרטים אישיים.

חלק ו' - מבנה נתונים וכללי אבטחה
══════════════════════════════════════
מבנה ב-Realtime Database:
- english/users/<uid>/profile - שם, אימייל או שם משתמש, כניסה אחרונה
- english/users/<uid>/progress - { data: {כל מפתחות ההתקדמות כמחרוזות}, clientUpdatedAt, updatedAt }
- english/admins/<uid> = true
- english/content/custom/<מאגר>/<id> - שאלות שנוספו; english/content/hidden/<מאגר>/<id> = true - מובנות שהוסתרו
- english/visits/<YYYY-MM-DD>/<visitorId> = { t, s: מחובר?, n: מספר כניסות }
- english/presence/<visitorId> = { t, s }

כללי אבטחה (database.rules.json) - להכין קובץ ולהנחות אותי להדביק אותו בקונסול:
- כל ילד קורא וכותב רק את english/users/<uid> שלו; מנהלים קוראים את כל english/users.
- admins - כל אחד קורא רק את הרשומה שלו; אין כתיבה מהאפליקציה.
- content - קריאה לכולם; כתיבה רק למנהלים.
- visits / presence - כתיבה לכולם רק בפורמט תקין (תאריך ומזהה לפי regex, t מספר <= now, s בוליאני, n בין 1 ל-1000, בלי שדות נוספים); קריאה רק למנהלים.
- כל השאר חסום.

חלק ח' - סדר העבודה
══════════════════════════════════════
1. קרא את החומרים ששלחתי, ותכנן את רשימת הנושאים והאריחים. הצג לי ואשר איתי.
2. בנה את אפליקציית התרגול עם מאגר שאלות עשיר לכל נושא (לפחות 30 שאלות בכל נושא דקדוק, כ-150 מילים, 6-8 קטעי קריאה ו-5-6 קטעי האזנה מותאמים לגיל), כולל השאלות מהחומרים שצירפתי.
3. הוסף שיעורי "איך פותרים?".
4. הנחה אותי ליצור פרויקט Firebase (Realtime Database באירופה, מצב locked; Authentication עם Google ו-Email/Password; רישום Web App וקבלת firebaseConfig) ולהדביק את כללי האבטחה.
5. חבר התחברות, סנכרון לענן, תזכורת הרשמה לאורחים.
6. בנה את ממשק הניהול, והנחה אותי איך להגדיר את עצמי כמנהלת (העתקת ה-UID מ-Authentication ← Users והוספת english/admins/<UID> = true בלשונית Data).
7. הנחה אותי להעלות ל-GitHub ול-Vercel (פרויקט חדש, Root Directory אם צריך), ולהוסיף את כתובת האתר ל-Authentication ← Settings ← Authorized domains.
8. בסוף - תן לי רשימת בדיקה קצרה לוודא שהכול עובד.
