# 🎮 אפליקציית תרגול למבחן כיתה ד'

אפליקציה אינטראקטיבית לתרגול מתמטיקה לכיתה ד' עם שאלות דינמיות מבוססות AI.

## ✨ תכונות

- 🧮 **7 קטגוריות משחקים**: חיבור וחיסור, כפל וחילוק, מבנה עשרוני, בעיות מילוליות, חקר נתונים, צורות הנדסיות, מדידות
- 🤖 **שאלות דינמיות עם AI**: שאלות מגוונות ומעניינות שנוצרות בזמן אמת
- 🏆 **מערכת הישגים**: 11 הישגים שונים לעידוד התקדמות
- ⏰ **ספירה לאחור למבחן**: מעקב אחר הזמן שנותר
- 💾 **שמירת התקדמות**: כל ההתקדמות נשמרת ב-localStorage
- 🎨 **עיצוב מושלם**: ממשק משתמש יפה ואנימציות חלקות
- 📱 **רספונסיבי**: עובד מצוין על טאבלטים ומחשבים

## 🚀 התקנה

1. שכפל את הפרויקט:
```bash
git clone https://github.com/benpakmnz/grade4-quiz-app.git
cd grade4-quiz-app
```

2. התקן את התלויות:
```bash
npm install
```

3. קבל API key חינמי מ-Google Gemini:
   - גש ל-[Google AI Studio](https://makersuite.google.com/app/apikey)
   - התחבר עם חשבון Google
   - לחץ על "Create API Key"
   - העתק את ה-API key

4. צור קובץ `.env` בתיקיית הפרויקט:
```bash
REACT_APP_GEMINI_API_KEY=your_api_key_here
```

5. הרץ את האפליקציה:
```bash
npm start
```

האפליקציה תיפתח בדפדפן בכתובת: http://localhost:3000
